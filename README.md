# Калькулятор с переменными и историей

## Описание
Консольный калькулятор с поддержкой переменных, истории вычислений и арифметических операций.

## Функции
- Сложение, вычитание, умножение, деление
- Поддержка скобок
- Переменные (x = 10)
- История вычислений (history)
- Просмотр переменных (vars)

## Запуск
```bash
python calculator/main.py
